# 计算机科学专业学习经济学与金融的详细学习计划

## 📅 **总览：12个月系统学习路线**

### **核心理念**
**以计算机科学为杠杆，以项目实践为驱动，构建“技术+金融”复合能力体系**

---

## 📚 **第一阶段：基础认知构建（第1-3个月）**

### **目标**：建立经济金融世界观，培养基本直觉

### **详细安排**：

#### **第1个月：经济学原理与思维**
- **每周学习时间**：10-12小时
- **核心内容**：
  - 微观经济学基础概念
  - 宏观经济基本指标
  - 经济学思维方式

- **具体学习路径**：
  ```
  第1周：经济学思维入门
    - 阅读《经济学原理》第1-4章（曼昆）
    - 观看可汗学院经济学前10个视频
    - 完成练习：用机会成本分析你的时间分配
  
  第2周：市场机制与价格
    - 阅读《经济学原理》第5-7章
    - 学习Python基础数据分析：安装Anaconda，学习pandas基础
    - 项目：爬取某商品历史价格（如CPU），绘制价格趋势图
  
  第3周：企业行为与市场结构
    - 阅读《经济学原理》第13-17章
    - 学习市场结构（完全竞争、垄断等）
    - 思考：科技公司属于哪种市场结构？
  
  第4周：宏观经济指标
    - 阅读《经济学原理》第23-25章
    - 学习GDP、CPI、失业率的计算方法
    - 实践：从国家统计局网站下载GDP数据并用Python分析
  ```

#### **第2个月：金融基础与编程入门**
- **核心内容**：
  - 金融基本概念
  - 货币时间价值
  - Python金融数据处理基础

- **具体学习路径**：
  ```
  第1周：金融学基础
    - 阅读博迪《金融学》第1-5章
    - 学习：货币的时间价值、风险与收益
    - Python实践：编写复利计算器
  
  第2周：金融市场概览
    - 了解股票、债券、基金等基本工具
    - 学习基本的财务指标（PE、PB、ROE等）
    - 实践：使用akshare或yfinance获取股票数据
  
  第3周：投资基础
    - 阅读《漫步华尔街》前5章
    - 理解有效市场假说
    - 项目：模拟定投策略计算器
  
  第4周：编程技能专项
    - 系统学习pandas数据处理（官方教程前10章）
    - 学习matplotlib基础绘图
    - 项目：分析某指数基金历史收益
  ```

#### **第3个月：工具整合与项目实践**
- **目标**：将经济学概念与编程工具初步结合
- **核心项目**：宏观经济数据分析仪表盘
  ```
  项目要求：
  1. 从FRED或中国统计局获取以下数据：
     - 中国/美国GDP增长率
     - 通货膨胀率
     - 失业率
     - 利率
  
  2. 用Python实现：
     - 数据清洗与预处理
     - 可视化（折线图、柱状图）
     - 简单的相关性分析
  
  3. 制作Jupyter Notebook报告，包括：
     - 数据来源说明
     - 分析方法
     - 主要发现
     - 代码注释
  ```

## 🧠 **第二阶段：理论深化与工具掌握（第4-9个月）**

### **目标**：系统学习核心理论，掌握量化分析工具

### **详细安排**：

#### **第4-5个月：微观经济学与优化理论**
- **每周学习时间**：12-15小时
- **重点**：最优化理论与计算机应用的结合

- **学习路径**：
  ```
  微观经济学深化：
    - 教材：范里安《微观经济学：现代观点》
    - 重点章节：消费者理论（2-6章）、生产者理论（19-22章）
    - 特别关注：最优化问题的数学表达
  
  数学工具强化：
    - 复习：微积分中的极值问题
    - 学习：线性规划基础
    - Python库：SciPy优化模块
  
  编程项目：
    项目1：消费者效用最大化求解器
      - 实现：给定预算和价格，求最优消费组合
      - 使用：SciPy的optimize模块
    
    项目2：企业利润最大化模拟
      - 模拟不同市场结构下的企业决策
      - 可视化：成本曲线、收益曲线、利润曲线
  ```

#### **第6-7个月：宏观经济学与时间序列分析**
- **学习路径**：
  ```
  宏观经济学核心：
    - 教材：曼昆《宏观经济学》
    - 重点：IS-LM模型、AD-AS模型、经济增长理论
    - 实践：关注美联储/人民银行政策报告
  
  计量经济学入门：
    - 教材：伍德里奇《计量经济学导论》前6章
    - 重点：线性回归、假设检验
    - Python库：statsmodels、scikit-learn
  
  时间序列分析基础：
    - 学习：ARIMA模型概念
    - 实践：用Python分析CPI时间序列
    - 项目：宏观经济指标预测（简单线性回归）
  ```

#### **第8-9个月：投资学与量化分析基础**
- **学习路径**：
  ```
  投资理论：
    - 教材：博迪《投资学》或《主动投资组合管理》
    - 核心内容：
      * 投资组合理论（马科维茨）
      * CAPM模型
      * 有效市场假说深化
  
  量化分析技能：
    - 统计学深入：假设检验、p值、置信区间
    - 金融数据分析：
      1. 收益率计算（日收益率、对数收益率）
      2. 波动率计算（历史波动率）
      3. 夏普比率、最大回撤
  
  大型项目：投资组合分析系统
    要求：
    1. 选择5-10只股票/基金
    2. 计算每只资产的历史收益率和波动率
    3. 实现马科维茨均值-方差优化
    4. 绘制有效前沿
    5. 计算投资组合的夏普比率
    6. 可视化：收益曲线、回撤曲线、相关性热力图
    
    技术栈：
    - 数据获取：akshare/yfinance
    - 优化：cvxopt或PyPortfolioOpt库
    - 可视化：plotly或seaborn
  ```

## 🎯 **第三阶段：专业方向选择与实践（第10-12个月及以后）**

### **根据兴趣选择1-2个方向深入**

### **方向A：量化金融/算法交易**

#### **学习路径**：
```
第10个月：金融工程基础
  - 教材：约翰·赫尔《期权、期货及其他衍生品》
  - 学习：衍生品基础、Black-Scholes模型
  - 项目：期权定价计算器（蒙特卡洛模拟）

第11个月：交易策略与回测
  - 学习内容：
    1. 常见交易策略（动量、均值回归、配对交易）
    2. 回测框架原理
    3. 过度拟合问题
  
  - 实践项目：
    1. 实现双均线策略
    2. 使用backtrader或zipline回测
    3. 分析策略表现（夏普比率、最大回撤、胜率）

第12个月：机器学习应用
  - 学习：金融中的机器学习（监督学习为主）
  - 项目：基于机器学习的股价预测
    * 特征工程：技术指标（RSI、MACD、布林带）
    * 模型：LightGBM/XGBoost
    * 注意：强调风险，不追求高精度
```

### **方向B：金融科技**

#### **学习路径**：
```
第10个月：区块链与加密货币
  - 学习内容：
    1. 区块链基本原理
    2. 比特币、以太坊技术架构
    3. 智能合约概念
  
  - 实践项目：
    1. 使用web3.py与以太坊测试网交互
    2. 编写简单智能合约（Solidity基础）

第11个月：信贷风控与数据科学
  - 学习内容：
    1. 信用评分卡模型
    2. 特征工程（WOE、IV值）
    3. 逻辑回归模型
  
  - 项目：基于公开数据的违约预测
    * 数据集：Lending Club数据
    * 模型：逻辑回归/XGBoost
    * 评估：KS值、AUC

第12个月：支付系统与API开发
  - 学习：现代支付系统架构
  - 项目：模拟交易系统API
    * 技术：FastAPI + PostgreSQL
    * 功能：用户管理、账户管理、模拟交易
```

### **方向C：经济数据分析与政策评估**

#### **学习路径**：
```
第10个月：高级计量经济学
  - 学习：面板数据模型、双重差分法（DID）
  - 实践：使用中国城市面板数据分析政策效应

第11个月：网络爬虫与另类数据
  - 学习：大规模数据采集
  - 项目：爬取电商价格数据，分析通胀
    * 技术：Scrapy/Selenium
    * 分析：价格指数构建

第12个月：数据可视化与仪表盘
  - 学习：Dash/Streamlit
  - 项目：经济数据交互式仪表盘
    * 功能：多维度筛选、动态图表、数据导出
```

## ⚠️ **重要注意事项**

1. **风险管理**：
   - 学习期间使用模拟账户或历史数据
   - 理解所有模型都有假设和局限性
   - 金融市场的复杂性远超任何模型

2. **学习心态**：
   - 经济学金融学是不断发展的学科
   - 关注现实世界的变化（政策、技术、市场）
   - 培养批判性思维，不盲从任何理论

3. **职业发展建议**：
   - 第6个月后可以开始关注实习机会
   - 第9个月后可以准备相关岗位面试
   - 建立专业网络（LinkedIn、行业会议）

4. **时间管理**：
   ```
   建议每周分配：
   - 理论学习：8小时
   - 编程实践：10小时
   - 阅读行业资讯：2小时
   - 项目开发：6小时
   - 复盘与计划：2小时
   ```

# 学习的第一性原理 
- **核心**：自学（而非补课） 
 - **自学的第一性原理**：归纳与总结（而非耗时间） 
 - **总结的第一性原理**：自己输出（而非抄笔记） 
 - **自己输出的第一性原理**：表达（而非重复） 
 - **表达的第一性原理**：逻辑（而非形式） 
 - **逻辑的第一性原理**：理解（而非模板）
